The Orchestrator

Coordinate ChatGPT, Gemini and Perplexity into a parallel multi-agent pipeline — plan, route, execute, synthesize, and ship files. REST transport, no browser tabs, no API keys.

v3.0 Web2API transport 86 tests Zero npm deps MIT
GitHub Quick start

#What it does

One goal in, a coordinated team of AI agents out.

🧠

Brain planning

ChatGPT (the brain) decomposes your goal into typed subtasks with dependency ordering.

⚡

True parallelism

Tasks run in parallel across agents — sequential within an agent to respect rate limits.

📚

Long-context handling

7500-char turn budget, long prompts split into chained conversation turns, outputs compacted before reuse.

📁

File creator harness

Extracts <file> blocks, writes traversal-safe paths, detects conflicts, zips the run.

🛡️

Resilience

Retry with exponential backoff + jitter, agent failover, reliability tracking, per-agent session memory.

🔌

Connectors

Push results to GitHub, upload to Google Drive, or fire a webhook — from the dashboard.

#Quick start

Three steps from clone to a running multi-agent pipeline.

1. Start the backend

# Web2API server (cookie-based REST for ChatGPT/Gemini/Perplexity)
cd vendor/web2api
python -m venv .venv
.venv\Scripts\pip install -e .
.venv\Scripts\python -m uvicorn web2api.server.app:app --host 127.0.0.1 --port 8080

# Orchestrator dashboard server (separate terminal)
npm run serve          # http://127.0.0.1:3000

2. Install the Cookie Bridge extension

npm run ext
# chrome://extensions → Developer mode → Load unpacked → extension/

On install the extension generates a pairing token, captures your ChatGPT / Gemini / Perplexity session cookies, and feeds them to the local server. Providers go Live instantly — no manual cookie extraction, no auth files to edit.

3. Run

node harness/index.js --goal "Build a landing page with a contact form"

…or open http://127.0.0.1:3000 and drive it from the dashboard.

#CLI

node harness/index.js --goal "<text>" [options]
  --agents chatgpt,gemini        restrict agents
  --out runs/                    run directory (files/ + zip)
  --confirm                      require confirmation before executing
  --base-url http://127.0.0.1:8080
  --api-key KEY                  if the server requires one
  --max-agents 4  --retries 2
  --file path                    include a project file (repeatable)
  --list-agents                  show agent registry
  --health                       check Web2API connectivity

Exit codes: 0 ok · 1 pipeline error · 2 bad usage · 3 Web2API unavailable.

#Architecture

harness/
├── index.js            # CLI entry
├── server.js           # Dashboard server: static UI + SSE + run/connector/cookie APIs
├── connectors.js       # GitHub / Google Drive / Webhook
├── orchestrator.js     # Pipeline: providers → plan → route → parallel exec → synthesis → files
├── web2api-client.js   # SSE client, retry/backoff, long-message turn splitting, session chaining
├── agents.js           # Agent registry + capability scoring
├── context.js          # Long-context budgeting (7500-char turns)
├── prompts.js          # Task / synthesis prompt builders
├── task-planner.js     # LLM task decomposition with cache + fallback
├── task-router.js      # Reliability tracking, load balancing, failover
├── file-harness.js     # <file> extraction, safe writes, conflict detection, pure-Node ZIP
└── store.js            # Atomic JSON KV store

extension/              # Chrome MV3 Cookie Bridge (auto-capture provider cookies)
ui/dashboard.*          # Claude-style dashboard (html/css/js)
vendor/web2api/         # Web2API backend (FastAPI, SSE, cookie-based)
src/, content/, ui/legacy  # Legacy v2 browser-extension code (unused by the harness)

#Notes

  • Cookies are session-based: they expire and may be IP-bound. Re-capture from the extension popup when a provider stops responding.
  • DeepSeek and HuggingFace agents were removed — Web2API has no API path for them.
  • ChatGPT needs its Bearer token for full API access — the extension grabs it from localStorage when available (best effort). Gemini and Perplexity are cookie-only.
  • The legacy Chrome extension (src/, content/, ui/legacy) is kept for reference; the harness is the supported path.
